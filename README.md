# Conture Make-Up Bratislava – návrhy webu

Statické HTML (bez buildu). Otvor `index.html` – rozcestník na 3 návrhy:

- `navrh-1/` Atelier – editoriálny luxus (krémová/zlatá, serify)
- `navrh-2/` Fresh Clinic – svetlý, tyrkysový, karty + FAQ
- `navrh-3/` Noir – tmavý, odvážna typografia, ružový akcent

Zdroj obsahu: https://conturemakeup.sk/ (len pobočka Bratislava; Žilina zatiaľ vynechaná).
`_src/` = stiahnuté originálne obrázky z pôvodného webu (git ich ignoruje).
